# Provisional assets

The five zinc processing item icons are original 16×16 PNGs generated by `tools/generate_icons.py` using a small Python standard-library PNG writer and hand-authored pixel silhouettes. The silhouettes and provisional colors distinguish dust, dirty dust, clump, shard, and crystal. These are initial author-created assets under the project's MIT license; see `LICENSE`. They are placeholders for playtesting and are not release-ready. Final art is pending.

Slurry visuals use Mekanism's existing chemical textures, supplied by the installed Mekanism dependency; this project does not copy or redistribute those texture files. The texture resources in Mekanism 10.7.19.85 are `mekanism:textures/slurry/dirty.png` for dirty slurry and `mekanism:textures/slurry/clean.png` for clean slurry.
