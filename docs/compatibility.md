# Compatibility targets

The initial compatibility target is intentionally narrow:

| Component | Target |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.252 |
| Java | 21 |
| Create | 6.0.10 |
| Mekanism | 10.7.19.85 |

This addon registers the following IDs in namespace `create_mekanism_zinc`:

- Items: `dust_zinc`, `dirty_dust_zinc`, `clump_zinc`, `shard_zinc`, `crystal_zinc`.
- Mekanism chemicals: `dirty_zinc`, `clean_zinc`.

These are the milestone 1 targets, not a claim of compatibility with other versions. Update this table only after checking the exact game, loader, and dependency versions together.
